# Contributing

Focused suggestions and pull requests are welcome, especially when they make the portfolio clearer, more accessible, or more accurate.

## Useful contributions

- Accessibility and keyboard-navigation improvements.
- Responsive-layout fixes across common screen sizes.
- Corrections to project descriptions or links.
- Performance improvements that preserve the visual character.
- Tests for visible claims, navigation, or project boundaries.

Please keep pull requests narrow and describe the reader-facing effect. Do not add trackers, advertising, contact-data collection, new external services, or claims about a project that its own repository does not support.

Opening an issue or pull request does not guarantee a response, merge, roadmap commitment, or future maintenance.
